# 📊 Sankey Rotation App

แอป Streamlit สำหรับแสดงผล **Sankey Diagram** จากไฟล์ Excel ข้อมูลการโยกย้ายบุคลากร

## 🚀 วิธีใช้งาน
1. อัปโหลดไฟล์ Excel ที่มี sheet `ตารางรายละเอียด`
2. เลือก Filter (ฝ่ายเดิม / ฝ่ายใหม่)
3. เลือกโหมดแสดงผล
   - ซ่อนชื่อ (ระดับฝ่าย)
   - แสดงชื่อบุคคล
4. กราฟ Sankey จะอัปเดตอัตโนมัติ

## ☁️ Deploy บน Streamlit Cloud
1. Fork หรือ clone repo นี้
2. ไปที่ [streamlit.io/cloud](https://streamlit.io/cloud)
3. เลือก repo → กด Deploy
4. แชร์ลิงก์แอปให้ผู้ใช้ได้ทันที 🚀
